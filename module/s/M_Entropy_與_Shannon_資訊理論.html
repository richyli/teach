# 你會的能力 讓你能解釋的真實問題
1 解釋資訊量與「字數／檔案大小」無關（砍一半 = 1 bit） 為什麼老闆那封落落長的信，其實沒告訴你任何新東西？為什麼「已讀不回」有時資訊量比長篇大論還大？
2 計算給定機率分布的 $H = -\sum p_i \log_2 p_i$ 一個「八卦」到底多有料？把它的可能結果與機率列出來算 H，就知道它消除了多少不確定性。
3 判斷為什麼「越偏斜 → entropy 越低」 為什麼 AI 生圖會有性別偏見？——訓練資料裡「護理師→女性」「工程師→男性」的分布極度偏斜（低 entropy），模型學到的就是這個近乎必然的關聯，於是生圖時幾乎只輸出該性別。偏見的數學本質，就是某個條件分布的 entropy 太低。
4 連結 entropy 到壓縮／通訊／cross-entropy loss 為什麼隨機亂碼 zip 不動、而重複的文字壓得很小？為什麼 AI 訓練說穿了就是在「降低預測的 entropy」？
學生閱讀｜Shannon 是誰，為什麼傳播學院要上他

Claude Shannon（1916–2001）不是傳播學者，是數學家兼工程師，在貝爾實驗室工作。 他 1948 年那篇〈A Mathematical Theory of Communication〉要解決的是一個很實際的問題： 電話線有雜訊，訊號會失真，那到底一條線最多能可靠地傳多少東西？

他對「傳播效果」「說服」「閱聽人」完全沒有興趣。但他為了回答那個工程問題， 順手做了一件事——把「資訊」變成一個可以計算的量。這件事後來外溢到所有地方： 網路、壓縮（ZIP、JPEG）、密碼學、基因定序，以及今天的語言模型。

傳播學院熟悉的「Shannon-Weaver 模式」其實是後人把他的數學圖轉成傳播模式的結果， 而 Weaver 也是數學家。你在傳播理論課本看到的那個框框圖，原本是電路圖。

這件事本身就值得記住：一個為了省電話線成本而發展出來的量尺， 七十幾年後變成解釋 AI 為什麼會胡說八道的工具。

    學生閱讀｜這一段你自己讀就懂

    「資訊」在日常語言裡很模糊，Shannon 把它定成一件可以量的事：資訊就是消除掉的不確定性。

    想像你要猜一件事，一開始有很多種可能。每得到一則消息，可能性就少一些。 少得越多，那則消息的資訊量就越大——跟它有幾個字、檔案多大完全無關。 一句「你被資遣了」只有五個字，卻把你對未來的所有猜測整個翻掉； 老闆八百字的勉勵信講的全是你早就知道的事，資訊量趨近於零。

    量尺的單位是 bit：能把可能性砍成一半的消息，就是 1 bit。 猜 1 到 100 的數字，每次問一個能砍一半的是非題，大約七題就會收斂。

    Shannon 的 entropy 公式（量化）

    Shannon（1948）把上面的直覺寫成一條公式。對一個有 $n$ 種可能結果、每種發生機率為 $p_i$ 的隨機事件，它的熵 entropy是：

    $$H = -\sum_{i=1}^{n} p_i \log_2 p_i$$

    讀法：把每個結果的「意外程度」$-\log_2 p_i$（機率越小、越意外、值越大），用它自己的機率 $p_i$ 加權平均。H 就是「平均每次結果帶來的資訊量（bits）」，也就是這個系統的平均不確定性。

    三個直覺要記住

    1. 越意外 → 資訊量越大：單一結果的資訊量 $-\log_2 p_i$。機率 $p=1$（一定發生）→ 資訊量 $0$（毫不意外）；機率越小 → 值越大。
    2. 越均勻 → entropy 越高：所有結果一樣可能時最不確定、H 最大。
    3. 越偏斜 → entropy 越低：某個結果幾乎必然發生時，幾乎沒有不確定性、H 接近 0。

    算一遍：硬幣

    • 公正硬幣（正反各 0.5）： $$H = -(0.5\log_2 0.5 + 0.5\log_2 0.5) = -(0.5\times(-1)+0.5\times(-1)) = 1 \text{ bit}$$ 最不確定，達到兩種結果的上限。

    • 作弊硬幣（正面 0.9、反面 0.1）： $$H = -(0.9\log_2 0.9 + 0.1\log_2 0.1) \approx 0.47 \text{ bits}$$ 比較好猜，不確定性掉了一半以上。

    • 雙面都正面（正面 1.0）：$H = 0$。結果早就知道，沒有任何資訊。

    再算兩個：骰子與世界盃

    • 公正骰子（六面各 1/6）：$H = \log_2 6 \approx 2.58$ bits。比硬幣不確定，因為選項多了。
    • 32 隊等可能：$H = \log_2 32 = 5$ bits。這就是開場那個遊戲的答案。
    • 德國 99%、其餘 31 隊平分 1%：$H \approx 0.10$ bit。

    最後這一個是本節最重要的數字。同樣是 32 隊，同樣的比賽，不確定性從 5 bit 掉到 0.1 bit—— 掉的不是隊伍數量，是你對它們的了解。所以：

    資訊量不是消息本身的性質，是消息與接收者之間的關係。 同一則「德國奪冠」的快報， 對懂足球的人幾乎沒有資訊量，對完全不懂的人是滿滿 5 bit。這也是為什麼「這則新聞重不重要」 永遠要問「對誰」。

    一張圖記住：兩種結果時，H 隨機率畫出一條倒 U——兩端（0 或 1）是 0，正中央（0.5）是最高的 1 bit。最公平 = 最不可預測 = 資訊量最大。

      學生閱讀｜公式在說什麼

      $H = -\sum p_i \log_2 p_i$ 看起來嚇人，意思其實只有一句： 把每一種可能結果的「意外程度」，按它發生的機率加權平均起來。

      • 越不可能發生的事，一旦發生越意外，帶來的資訊越多
      • 但它很少發生，所以在平均裡佔的權重小
      • 兩者相乘再加總，就是這個分布的平均不確定性

      結論只要記三句：分布越平均，entropy 越高；越偏斜，entropy 越低； 只有一種結果時 entropy 是 0（沒有不確定性，也就沒有資訊可言）。 上面那個互動工具就是在讓你把這三句話拉出來看。

      ⚠️ 常見迷思

      學生算完硬幣後最容易卡在這三點，講授時主動點破：

      迷思 為什麼錯 攔截方式
      「資訊量 = 字數／檔案大小」 一封寫滿廢話的長信，消除的不確定性是 0 → 資訊量 0 回扣 15′a 的「廢話長信」反例
      「entropy = 亂 = 壞東西」 entropy 是中性量尺，量的是不確定性／資訊潛能；高 entropy 代表「可承載的資訊多」，不是混亂 強調單位是 bit，是量尺不是價值判斷
      「$-\log_2 p$ 算出來是負的吧？」 $p<1$ 時 $\log_2 p<0$，前面加負號後為正；$p=1$ 時為 0 帶你代一個數（如 $-\log_2 0.5 = 1$）親手驗證

      為什麼這跟「資料、壓縮、AI」有關（應用橋接）

      Shannon 的 entropy 不只是數學玩具，它定了三件現實世界的底線：

      1. 壓縮的極限：一段資料平均最少要用 $H$ 個 bits 才能無損表示。entropy 低（很有規律）→ 可以壓很小（zip 很有效）；entropy 高（很隨機）→ 壓不動。「壓不壓得動」直接反映「有多少真資訊」。
      2. 通訊的極限：Shannon 證明了在有雜訊的通道上，能可靠傳輸的速率有上限（channel capacity）。今天的 Wi-Fi、4G/5G 都建在這條定理上。
      3. 預測與學習：機器學習裡的 cross-entropy loss，量的就是「模型的預測分布」離「真實答案」差多少 bits——模型訓練本質上就是在「降低預測的 entropy／不確定性」。這條線直接接到下一個模組：資訊理論與不確定性 與 Harness Engineering 與資訊熵。

      這一堂收束成一句話：資訊 = 消除不確定性；entropy = 平均不確定性的量尺（單位 bit）。記住那條倒 U——越均勻越不確定，給的資訊越多。
