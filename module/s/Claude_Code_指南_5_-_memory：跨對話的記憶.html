Claude Code 指南 5｜memory：跨對話的記憶

在本單元中，會介紹 memory 跟 CLAUDE 守則差在哪、記憶檔實際長什麼樣、怎麼讓它把一條規則記下來，以及一條記憶要寫成什麼樣子才不會被死板套用。

兩套記憶並存，差別在誰寫的

CLAUDE 守則 memory
誰寫 你 它自己寫
內容 規則與指令 你的偏好、你糾正過的事、它從對話學到的脈絡
綁在哪 專案（或你的所有專案） 這台機器上的這個專案
何時載入 每次對話 每次對話載入索引

兩套都在對話一開始就進來。你要規定它怎麼做，寫 CLAUDE 守則；你糾正它一次、希望它以後自己記得，那是 memory。

記憶檔在哪、長什麼樣

每個專案有自己的記憶資料夾，位置是：

~/.claude/projects/<專案>/memory/
├── MEMORY.md            ← 索引，一則記憶一行，每次對話都會載入
├── user_role.md         ← 一則記憶一個檔
├── feedback_用字.md
└── ...

MEMORY.md 是目錄，只放一行一則的摘要；細節在各自的主題檔裡，它需要的時候才去讀。這樣設計的理由是省 context：索引只載入前兩百行或 25KB，塞爆了超出的部分就不會被讀到。

它存的記憶分四類，會標在檔案開頭：

類型 存什麼 你單位的例子
user 你是誰、你的專業與偏好 我是新聞部主管，負責晚間時段
feedback 你給過的糾正、你確認過的做法 公文不要用「爰此」開頭
project 進行中的工作、期限、決策 十月底前要交出編輯室 AI 守則 v1
reference 資料在哪裡 收視率報表在某個共用資料夾

它會自動跳過兩種東西：看檔案就知道的事，以及 CLAUDE 守則裡已經寫過的事。

讓它記住的兩種方法

第一種，你直接說。 糾正完之後補一句：

把這個規則記下來，以後自動套用。

第二種，它自己觀察。 自動記憶預設開著，你反覆糾正同一件事，它會主動寫進去。畫面上出現「已儲存 N 則記憶」就是它在寫。

第一種比較可靠。光糾正一次而沒有明說要記下來，下次它很可能照犯。這一句是整份指南裡投資報酬率最高的一句話。

要看它到底記了什麼，在對話裡打 /memory，選記憶資料夾就能瀏覽。全部是純文字，你可以自己改、自己刪。記錯的就刪掉，不會有任何副作用。

不想讓它自動記的話，/memory 裡有開關可以關掉。

一條記憶要寫成什麼樣子

差的寫法：

中文不要用破折號

好的寫法：

中文寫作禁止用破折號當插入語。
  Why: 台灣中文書寫慣例不用夾注式破折號，改稿時編輯會改掉。
  How to apply: 出現「——X——」的插入語，一律改成「，例如 X 等，」
                或用括號，或重組句子讓語意直接。

差別在後面兩行。加上為什麼跟怎麼套用，遇到邊角情況它才判斷得出該不該套。只寫結論的規則會被死板套用，然後在不該套的地方出包。

這一點跟你帶人一模一樣：只交代「不要這樣做」的新人會在沒交代過的情境裡犯錯，知道理由的新人不會。

規則該寫在哪一層

同一條糾正，可以寫進三個地方，選錯層級會讓它在不該生效的地方生效：

這條規則的適用範圍 寫在哪
只跟某一個固定流程有關 那個 skill 的 SKILL.md
這個資料夾的所有工作都要遵守 專案的 CLAUDE.md
關於你這個人的偏好，換專案也成立 memory

換一台電腦它就失憶

記憶存在你這台機器上，不會跟著帳號跑。你在辦公室訓練了三個月，回家開筆電是一張白紙。這是很多人第一次踩到的坑。

要跨機器共用，把 .claude 資料夾放進雲端同步資料夾再做連結，設定方式因系統而異。這件事本身就可以叫它幫你做：描述你的情況（幾台電腦、用哪個雲端硬碟、哪個作業系統），讓它規劃步驟。你不需要自己去查。

要注意的是兩台電腦不要同時開同一個對話，雲端同步處理不了同時寫入。

這件事就是「訓練 AI」的真相

沒有 GPU、沒有資料集、沒有微調。就是「做一次、糾正、記下來」重複幾十次。

真實的例子：有人累積了六十幾條自己寫作風格的記憶，從「動詞要口語」到「結尾不要寫『療癒了疲憊的旅人』」都有。之後叫它寫同類型的短文，初稿就是本人的口吻，不是雜誌文案腔。這些規則不是一次寫好的，是一篇一篇對照出來的。

這種做法比微調模型好的地方有四個：不用準備資料、規則你看得懂也改得動、複製給同事他立刻有同一套、寫錯了刪掉那一行就好。

帶回你的編輯室

memory 在機構裡會變成一個棘手的題目，值得先想清楚：

  • 員工花一年訓練出來的 memory，裡面有客戶偏好、業務判斷、審稿心法。那是公司資產還是個人資產？
  • 員工離職時應該帶走嗎？不能帶走的話，公司要付什麼？
  • 公司要不要在新人到職時給一份起手記憶包，省他從零摸索？
  • 「這個月我把 AI 教會了什麼」如果變成月報的一欄，會比現在的月報有用嗎？

檢查清單

  • [ ] 你知道 /memory 怎麼打開，也看過裡面有什麼
  • [ ] 你至少讓它記過一條你自己的用語規則
  • [ ] 那條規則有寫為什麼，不是只有結論
  • [ ] 你判斷得出一條規則該進 skill、CLAUDE 守則、還是 memory
  • [ ] 你知道換電腦會失憶
