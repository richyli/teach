練習 09 - 付費牆讓流量掉幾成

在本單元中，會介紹第 9 題「總經理要一個數字：一篇稿子關進付費牆，流量會掉幾成」從頭到尾實際跑一次的方法、跑出來的數字，以及畫出來的圖。

這一頁是做完之後對答案用的。還沒動手的話，先回 Hub - 資料分析練習案例庫 找到這一題，照「怎麼做」那一欄自己跑一次再回來。

題目

有人會這樣問你：「讀者事業處想再把三百篇稿子推進付費牆。給我一個數字：一篇稿子關進去，瀏覽量大概掉幾成？掉的量換到的訂閱划不划算？」
難度 進階
組別 第 3 組：這個差異是真的嗎
用哪張表 content_monthly_flat（L1 檔名 content_monthly_2024_10.csv）
對應單元 為什麼這篇會紅 用迴歸找關聯

方法

三條逐步加控制的 OLS 迴歸，依變數都是 log(pv)——瀏覽量右偏得很厲害（中位數 446、最大 5869），取對數以後係數可以直接讀成百分比。A：只放 is_paywalled。B：加 content_type、log(word_cnt)、has_number_in_headline。C：再加 section_name 當版面的固定效果。把三條的 is_paywalled 係數、p 值、R 平方並排看。語言用 Python：statsmodels 的 formula 寫法，C(section_name) 一個字就把 18 個版面展開成虛擬變數，不必自己動手做 18 欄，改規格只要改字串。

程式

這一題用 Python，整支程式如下。資料放在 dist/L1 與 dist/L2 兩個資料夾。

from itertools import combinations

from _kmg import *
import statsmodels.formula.api as smf

r = R(9, "總經理要一個數字：一篇稿子關進付費牆，流量會掉幾成")
f = dedupe(flat()).copy()
f["lpv"] = np.log(f["pv"])
f["lwc"] = np.log(f["word_cnt"])
f["pw"] = f["is_paywalled"].astype(int)
f["hn"] = f["has_number_in_headline"].astype(int)
r.chk("pv 中位數", 446, float(f["pv"].median()), tol=0.5)
r.chk("pv 最大值", 5869, int(f["pv"].max()))

specs = {"A": "lpv ~ pw",
         "B": "lpv ~ pw + C(content_type) + lwc + hn",
         "C": "lpv ~ pw + C(content_type) + lwc + hn + C(section_name)"}
exp = {"A": (-0.214, 0.0001, 0.010), "B": (-0.103, 0.083, 0.070), "C": (-0.291, 0.0014, 0.490)}
res = {}
for k, fm in specs.items():
    m = smf.ols(fm, data=f).fit()
    res[k] = m
    b, pv, r2 = exp[k]
    r.chk("%s 付費牆係數" % k, b, float(m.params["pw"]), tol=0.002)
    r.chk("%s p 值" % k, pv, float(m.pvalues["pw"]), tol=max(pv * 0.5, 0.0005))
    r.chk("%s R 平方" % k, r2, float(m.rsquared), tol=0.002)
r.chk("C 規格換算成流量變化", -0.25, float(np.exp(res["C"].params["pw"]) - 1), tol=0.005)

rate = f.groupby("section_name")["pw"].mean()
full = sorted(rate[rate == 1].index)
r.chk("100% 進付費牆的版面", sorted(["財經", "科技", "環境", "深度調查"]), full)
others = rate.drop(full)
r.chk("其他版面多半在 15% 以下", True, bool((others < 0.15).mean() >= 0.5))
r.note("其他版面的付費比率：" + "、".join("%s %.0f%%" % (k, v * 100) for k, v in others.sort_values().items()))

# 課堂概念：搜尋空間。四組控制變數各自放或不放，一共 16 條規格
CTRL = {"內容型態": "C(content_type)", "字數": "lwc", "標題數字": "hn", "版面": "C(section_name)"}
curve = []
for k in range(5):
    for combo in combinations(CTRL, k):
        m = smf.ols("lpv ~ pw" + "".join(" + " + CTRL[c] for c in combo), data=f).fit()
        lo, hi = m.conf_int().loc["pw"]
        curve.append({"spec": "、".join(combo) or "不控制", "b": float(m.params["pw"]), "lo": float(lo),
                      "hi": float(hi), "p": float(m.pvalues["pw"])})
curve = pd.DataFrame(curve).sort_values("b").reset_index(drop=True)
r.chk("可以跑的規格數", 16, len(curve))
r.chk("付費牆係數 最小", -0.481, float(curve["b"].min()), tol=0.002)
r.chk("付費牆係數 最大", -0.100, float(curve["b"].max()), tol=0.002)
r.chk("在 0.05 下顯著的規格數", 12, int((curve["p"] < 0.05).sum()))

sig = [bool(res[k].pvalues["pw"] < 0.05) for k in "ABC"]
r.pit(sig == [True, False, True], "三條規格在 0.05 下顯著與否：A %s、B %s、C %s，多加一組控制就翻面" % tuple(
    "顯著" if s else "不顯著" for s in sig))
r.sc(bool((rate == 0).any() or (rate == 1).any()), "交叉表裡有版面是 100%% 進付費牆：%s" % "、".join(full))

fig, ax = plt.subplots(figsize=(9, 5))
colors = ["#4f81bd" if p < 0.05 else "#bbbbbb" for p in curve["p"]]
ax.errorbar(curve.index, curve["b"], yerr=[curve["b"] - curve["lo"], curve["hi"] - curve["b"]],
            fmt="none", ecolor="#999999", lw=1)
ax.scatter(curve.index, curve["b"], c=colors, zorder=3)
ax.axhline(0, color="black", lw=0.8)
ax.set_xticks(curve.index, curve["spec"], rotation=70, fontsize=8)
ax.set_ylabel("付費牆係數（log 瀏覽量）與 95% 信賴區間")
ax.set_title("同一個問題，16 條規格：係數從 -0.48 到 -0.10（藍點＝p < 0.05）")
save_fig(fig, "ex09_spec_curve.png")
r.save()

程式裡的 r.chk(項目, 預期值, 實算值) 是對照檢查，把入口頁寫的數字跟實際算出來的放在一起比；r.pit 記錄坑有沒有出現，r.sc 記錄自己驗那一步有沒有效。畫圖的部分在程式最後面。

程式開頭的 from _kmg import * 載入共用的讀檔、去重、換幣別與畫圖函式，內容在 練習 01 - 月會上的則數對不對 的「共用的讀檔函式」那一段。

結果

同一個問題，三條線給出三個答案。A：係數 -0.214、p=0.0001、R 平方 0.010。B：係數 -0.103、p=0.083，照慣例就是「不顯著」，R 平方 0.070。C：係數 -0.291、p=0.0014、R 平方 0.490。只交 B 會寫成「付費牆對流量沒有顯著影響」，只交 C 會寫成「有牆的稿子平均少掉約四分之一的瀏覽量」（exp(-0.291)-1 ≈ -25%）。差別在於付費牆不是抽籤決定的：財經、科技、環境、深度調查這四個版面 100% 進付費牆，其他版面多半在 15% 以下，不控制版面，你估到的其實是「財經跟娛樂的流量差多少」。

這題的坑，實際跑的時候有沒有出現

係數不等於因果。這題連「係數等於哪一個數字」都還沒站穩——多加一個控制變數就從不顯著變成 -0.29。付費牆是編輯政策按版面決定的，所以這條迴歸最多只能講「同一個版面、同一種型態、字數差不多的兩篇稿子，有牆的那篇平均少掉多少瀏覽量」，不能講「把這篇關進付費牆就會掉 25%」。這兩句話在會議上聽起來一樣，決策後果差很多。

實際跑的結果：三條規格在 0.05 下顯著與否：A 顯著、B 不顯著、C 顯著，多加一組控制就翻面。

自己驗那一步抓不抓得到錯

先印一張「每個版面的付費比率」交叉表。只要看到有版面是 0% 或 100%，就代表這個變數幾乎被版面決定，係數一定要控制版面之後才能報。然後問自己一句：「我的結論會不會多加一個控制變數就翻掉？」答案是會，那三條規格都要寫進報告，不能只挑好看的那一條交出去。

實際跑的結果：交叉表裡有版面是 100% 進付費牆：深度調查、環境、科技、財經。
