M Claude Code 串工作流

先修 M Claude Code 上手（已會安裝、會下三段式指令、懂 skill／hook／MCP 概念）。

🎯 學習目標

每條目標都是「一項能力 → 能解釋一個真實問題」。學這個不是為了多會一個功能，是為了把你每週都在重複做的爛事，包成一個一鍵叫用、還能自己接資料的流程。

# 你會的能力 讓你能解釋的真實問題
1 說明 skill＝可重複的固定流程、MCP＝接外部資料源的轉接頭 為什麼有了 skill 我就不用每週把同一串指令重打一遍？為什麼沒有 MCP，它只看得到我資料夾裡的檔？
2 設計並做出一個自己的 skill（週報彙整／選題評估／查證清單），必要時用 MCP 接資料 我每週都在做的哪件事，最值得包成 skill？值得做成 skill 的＝頻率高、步驟固定、輸入輸出講得清楚。
3 判斷一個 skill 為什麼跑歪——是 prompt 不夠明確，還是資料沒真的接上 為什麼別人照我的 skill 跑，結果卻不一樣？——拆開來看，多半是 prompt 留白讓 AI 自作主張，或它根本沒接到資料源、只是純文字模板。
  • 小作業：做出一個自己的 skill（週報彙整／選題評估／查證清單），寫成可分享說明。

💬 討論／分享／反思

  • 配對互評：兩人一組，互看對方剛動手做的 skill。重點問三件事：這個 skill 解決的是哪個會「重複做很多次」的工作？prompt 寫得夠明確、別人照著跑會不會跑歪？有沒有真的接到資料源（MCP／試算表／開放資料），還是只是純文字模板？
  • 一起收斂一題：哪一類工作最值得做成 skill？大家丟出自己想自動化的場景，一起判斷「值得做成 skill」的判準：頻率高、步驟固定、輸入輸出可描述。
  • 寫下個人反思：寫一句話，回答「我下週會把哪一件每週都在做的事，包成自己的第一個 skill？」並標出它最可能卡住的地方（是 prompt、還是資料接不上）。
