Claude Code 指南 2｜安裝 Claude Code 並登入

在本單元中，會介紹兩條安裝路線該怎麼選、帳號要哪一種、Windows 與 macOS 各自的指令怎麼打，以及裝完怎麼確認它真的活著。

先確認帳號，否則裝好也登不進去

Claude Code 需要付費帳號：Pro、Max、Team、Enterprise 訂閱，或 Claude Console 帳號。免費的 claude.ai 方案不包含 Claude Code。

如果你還沒付費，先用網頁版把純文字的任務做起來（見指南 0 的任務對照表），課堂上的示範看懂就好，回去再決定要不要開通。

兩條路線，第一次選擴充套件

擴充套件（圖形面板） CLI（終端機）
長什麼樣 VS Code 裡的對話面板，像聊天視窗 黑底白字的終端機
適合誰 第一次上手、不想碰終端機 想跑排程、跑批次、用完整功能
並排比對 有 有（會叫 VS Code 開）
功能完整度 大部分，少數指令只有 CLI 有 完整

先裝擴充套件，之後有需要再補裝 CLI。兩者共用同一份對話紀錄與設定，不會各記各的。

路線 A：安裝 VS Code 擴充套件

  1. 在 VS Code 按 Ctrl+Shift+X（Mac 是 Cmd+Shift+X）打開擴充套件。
  2. 搜尋 Claude Code，認明發行者是 Anthropic，套件識別名稱是 anthropic.claude-code。
  3. 按「安裝」。
  4. 裝好之後，開啟任何一個檔案，編輯器右上角會出現一個星形（Spark）圖示，點它就開啟 Claude 面板。左側活動列也會有同一個圖示。
  5. 第一次開面板會出現登入畫面，按「登入」，瀏覽器會跳出授權頁，用你的付費帳號完成授權後跳回 VS Code。

裝好沒出現圖示的話，按 Ctrl+Shift+P 打「Developer: Reload Window」重新載入視窗，通常就會出現。

路線 B：安裝 CLI

擴充套件自己帶了一份 CLI 給對話面板用，但你在終端機裡打 claude 需要另外裝一次。要跑排程、要用完整指令集的人才需要這一段。

Windows（PowerShell）

先確認你在 PowerShell 而不是 CMD：提示字元開頭有 PS 就是 PowerShell。

irm [https://claude.ai/install.ps1](https://claude.ai/install.ps1) | iex

如果被擋，出現無法載入指令碼的訊息，先跑這一行再重來：

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

機構網路擋掉下載的話，改用這個：

winget install Anthropic.ClaudeCode

macOS、Linux

curl -fsSL [https://claude.ai/install.sh](https://claude.ai/install.sh) | bash

用 Homebrew 也可以：

brew install --cask claude-code

Windows 使用者順便裝 Git for Windows 會少一些麻煩

到 <https://git-scm.com/downloads/win> 裝一次就好。裝了它，Claude Code 可以用 Bash 執行指令；沒裝的話它改用 PowerShell，多數情況一樣能用，但有些現成的腳本會挑環境。

裝好之後怎麼啟動

在 VS Code 的整合終端機（Ctrl+`）打 claude 就會啟動，而且它會自動偵測到自己在 VS Code 裡、接上編輯器。如果你用的是 VS Code 以外的終端機，在 Claude Code 裡打 /ide 手動連上。

確認它真的裝好了

在終端機打這兩行（只裝擴充套件的人可以跳過這一節）：

claude --version

正常會印出版本號，像 2.1.211 (Claude Code)。

claude doctor

這一行會印出安裝與設定的健康檢查，包含設定檔有沒有錯、自動更新是否正常。它只讀不寫，不會動到任何東西，卡住的時候第一個跑它。

更新怎麼處理

用官方安裝指令裝的版本會自己在背景更新，你不用管。用 winget 或 Homebrew 裝的不會自動更新，要自己跑：

winget upgrade Anthropic.ClaudeCode

brew upgrade claude-code

想立刻更新到最新版，任何安裝方式都可以跑 claude update。

完全不想碰終端機的話，還有桌面應用程式

Anthropic 另外出了 Claude Code 桌面應用程式，是純圖形介面，不需要終端機。下載頁在 <https://claude.com/download>。這門課的示範以 VS Code 為主，因為並排比對與 @ 帶檔的操作在 VS Code 裡最清楚，不過桌面版的概念完全一樣，四個零件也都在。

檢查清單

  • [ ] 確認你的帳號是付費方案（Pro、Max、Team、Enterprise 或 Console）
  • [ ] 擴充套件裝好，看得到星形圖示
  • [ ] 已完成瀏覽器授權，面板不再顯示未登入
  • [ ] （選配）終端機打 claude --version 印得出版本號
  • [ ] （選配）claude doctor 沒有紅字

卡住的話

症狀 原因 處理
command not found 或 'claude' 不是內部或外部命令 系統還不認得這個字，安裝沒完成或 PATH 沒設好 關掉終端機重開；仍不行就重跑一次安裝指令
出現 The token '&&' is not a valid statement separator 你在 PowerShell 卻貼了 CMD 的指令 改貼 PowerShell 那一行
出現 'irm' is not recognized 你在 CMD 卻貼了 PowerShell 的指令 開 PowerShell 再貼
裝了擴充套件但沒有圖示 視窗沒重載，或沒開啟任何檔案 Ctrl+Shift+P → Developer: Reload Window；並先開一個檔案
面板一直顯示未登入 授權沒完成，或瀏覽器跳轉失敗 從命令選擇區重新登入；換一個瀏覽器再試
下載中途失敗 機構網路阻擋 換網路，或改用 winget／Homebrew

更多症狀在 指南 8｜卡住了怎麼辦與安全守則。
