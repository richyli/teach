練習 08 - 自助平台點擊率真的比較高嗎

在本單元中，會介紹第 8 題「業務部要我證明自助下單平台的廣告比直客業務賣得好」從頭到尾實際跑一次的方法、跑出來的數字，以及畫出來的圖。

這一頁是做完之後對答案用的。還沒動手的話，先回 Hub - 資料分析練習案例庫 找到這一題，照「怎麼做」那一欄自己跑一次再回來。

題目

有人會這樣問你：「業務主管說自助下單平台的點擊率比我們直客業務高四成，要我們把好版位多留給自助平台。這個差距是真的嗎？大到值得改版位分配嗎？」
難度 入門
組別 第 3 組：這個差異是真的嗎
用哪張表 ad_daily（L1 檔名 ad_daily_2024_10.csv）
對應單元 從描述到推論 這個差異是真的嗎

方法

(1) 四個平台各自把 click_cnt 與 impression_cnt 先加總、再相除，得到整月 CTR（不是把每一列的 CTR 拿去平均）。(2) 對 kmg_selfserve 與 kmg_direct 做兩組比例的 z 檢定，報差值與 p。(3) 同一組比較，按 placement 拆成四個版位各做一次。(4) 想換算成錢的話，revenue 這一欄混了 TWD 與 USD，兩個程序化平台記的是美金，要先乘匯率 31.5 才能加。語言用 Python：這題只需要加總與一個 z 檢定，statsmodels.stats.proportion.proportions_ztest 直接吃「點擊數、曝光數」兩個數字，不必把上千萬次曝光展開成一列一個 0 或 1。

程式

這一題用 Python，整支程式如下。資料放在 dist/L1 與 dist/L2 兩個資料夾。

from _kmg import *
from statsmodels.stats.proportion import proportions_ztest

r = R(8, "業務部要我證明自助下單平台的廣告比直客業務賣得好")
a = ad()
a["twd"] = twd(a)
g = a.groupby("platform").agg(c=("click_cnt", "sum"), i=("impression_cnt", "sum"), t=("twd", "sum"))
ctr = g["c"] / g["i"]
r.chk("整月 CTR 自助（%）", 0.507, float(ctr["kmg_selfserve"] * 100), tol=0.0015)
r.chk("整月 CTR 直客（%）", 0.358, float(ctr["kmg_direct"] * 100), tol=0.0015)
r.chk("差距（百分點）", 0.149, float((ctr["kmg_selfserve"] - ctr["kmg_direct"]) * 100), tol=0.0015)
z, p = proportions_ztest([g.loc["kmg_selfserve", "c"], g.loc["kmg_direct", "c"]],
                         [g.loc["kmg_selfserve", "i"], g.loc["kmg_direct", "i"]])
r.chk("z", 58, float(z), tol=2)
r.chk("p 小到接近 0", True, bool(p < 1e-100))

two = a[a["platform"].isin(["kmg_selfserve", "kmg_direct"])]
gp = two.groupby(["placement", "platform"]).agg(c=("click_cnt", "sum"), i=("impression_cnt", "sum"))
cp = (gp["c"] / gp["i"] * 100).unstack()
for pl, es, ed in [("top_banner", 0.201, 0.185), ("in_article", 0.422, 0.402),
                   ("sidebar", 0.111, 0.110), ("video_preroll", 0.829, 0.859)]:
    r.chk("%s 自助（%%）" % pl, es, float(cp.loc[pl, "kmg_selfserve"]), tol=0.0015)
    r.chk("%s 直客（%%）" % pl, ed, float(cp.loc[pl, "kmg_direct"]), tol=0.0015)
mix = two.groupby(["platform", "placement"])["impression_cnt"].sum().unstack()
share = mix.div(mix.sum(axis=1), axis=0)
r.chk("自助曝光落在 video_preroll 的比例", 0.49, float(share.loc["kmg_selfserve", "video_preroll"]), tol=0.01)
r.chk("直客曝光落在 video_preroll 的比例", 0.18, float(share.loc["kmg_direct", "video_preroll"]), tol=0.01)
rpc = g["t"] / g["c"]
r.chk("每次點擊收入 最低平台", 16.6, float(rpc.min()), tol=0.06)
r.chk("每次點擊收入 最高平台", 17.3, float(rpc.max()), tol=0.06)
r.chk("直客整月曝光（萬）", 1769, float(g.loc["kmg_direct", "i"] / 1e4), tol=1)
extra = float(g.loc["kmg_direct", "i"] * (ctr["kmg_selfserve"] - ctr["kmg_direct"]))
r.chk("直客補到自助水準多出的點擊（萬）", 2.6, extra / 1e4, tol=0.06)

# 課堂概念：entropy。版位組成越集中，entropy 越低（四個版位平均分是 2 bits）
r.chk("版位組成 entropy 自助（bits）", 1.73, entropy_bits(share.loc["kmg_selfserve"]), tol=0.005)
r.chk("版位組成 entropy 直客（bits）", 1.96, entropy_bits(share.loc["kmg_direct"]), tol=0.005)

reversed_vp = bool(cp.loc["video_preroll", "kmg_direct"] > cp.loc["video_preroll", "kmg_selfserve"])
r.pit(p < 1e-100 and reversed_vp, "整月比較 p 值小到接近 0，拆到 video_preroll 卻是直客比較高（%.3f%% 對 %.3f%%）" % (
    cp.loc["video_preroll", "kmg_direct"], cp.loc["video_preroll", "kmg_selfserve"]))
diffs = (cp["kmg_selfserve"] - cp["kmg_direct"]).abs()
r.sc(bool(diffs.max() <= 0.149 / 5) or reversed_vp,
     "拆到版位後，兩個平台最大只差 %.3f 個百分點（整月差距的五分之一是 0.030），而且有一個版位方向相反" % float(diffs.max()))

order = ["video_preroll", "in_article", "top_banner", "sidebar"]
fig, ax = plt.subplots(1, 2, figsize=(10, 4))
x = np.arange(4)
ax[0].bar(x - 0.2, cp.loc[order, "kmg_selfserve"], 0.4, label="自助平台", color="#4f81bd")
ax[0].bar(x + 0.2, cp.loc[order, "kmg_direct"], 0.4, label="直客業務", color="#f79646")
ax[0].set_xticks(x, order, rotation=15)
ax[0].set_ylabel("點擊率（%）")
ax[0].set_title("同一個版位裡，兩個平台幾乎一樣")
ax[0].legend()
left = np.zeros(2)
for pl in order:
    vals = share.loc[["kmg_selfserve", "kmg_direct"], pl].values
    ax[1].barh(["自助平台", "直客業務"], vals, left=left, label=pl)
    left += vals
ax[1].set_xlabel("曝光落在各版位的比例")
ax[1].set_title("差別在版位組成：自助有一半曝光在 video_preroll")
ax[1].legend(fontsize=8, loc="upper left", bbox_to_anchor=(1.0, 1.0))
save_fig(fig, "ex08_ctr_by_placement.png")
r.save()

程式裡的 r.chk(項目, 預期值, 實算值) 是對照檢查，把入口頁寫的數字跟實際算出來的放在一起比；r.pit 記錄坑有沒有出現，r.sc 記錄自己驗那一步有沒有效。畫圖的部分在程式最後面。

程式開頭的 from _kmg import * 載入共用的讀檔、去重、換幣別與畫圖函式，內容在 練習 01 - 月會上的則數對不對 的「共用的讀檔函式」那一段。

結果

整月 CTR 自助 0.507%、直客 0.358%，差 0.149 個百分點，z 大約 58，p 小到印出來就是 0。但拆到版位就散掉了：top_banner 0.201% 對 0.185%、in_article 0.422% 對 0.402%、sidebar 0.111% 對 0.110%，而 video_preroll 反過來是直客比較高（0.859% 對 0.829%）。真正的差別在版位組成：自助平台有 49% 的曝光落在 CTR 最高的 video_preroll，直客只有 18%。再把每次點擊帶進的收入算出來，四個平台是 16.6 到 17.3 元，幾乎一樣——因為這門生意是照曝光計價的。

這題的坑，實際跑的時候有沒有出現

顯著不等於重要。曝光數以千萬計，任何 0.01 個百分點的差距都會拿到接近 0 的 p 值；p 在這裡只證明「這個差距不是抽樣抽出來的」，完全沒回答「這個差距值不值錢」。而差距的來源又是分母結構不同（兩個平台的版位組成不一樣），不拆版位就是拿版位差異當平台差異。

實際跑的結果：整月比較 p 值小到接近 0，拆到 video_preroll 卻是直客比較高（0.859% 對 0.829%）。

自己驗那一步抓不抓得到錯

把「差 0.149 個百分點」換算成一句有東西的話：直客整月 1769 萬次曝光，CTR 補到自助的水準也只多出約 2.6 萬次點擊，而收入是照曝光算的、一次點擊也不會多賺。然後把四個平台的 CTR 按版位拆開再看一次，如果差距縮到五分之一以下甚至反向，原本的結論就是版位組成造成的，不是平台好壞。

實際跑的結果：拆到版位後，兩個平台最大只差 0.030 個百分點（整月差距的五分之一是 0.030），而且有一個版位方向相反。

連到課堂概念

entropy

四個版位平均分配是 2.00 bits；自助平台的曝光組成只有 1.73 bits，直客是 1.96 bits。自助平台的曝光比較集中，集中在點閱率最高的 video_preroll，這個組成差異才是整月點閱率差距的來源。見 Entropy 與 Shannon 資訊理論
