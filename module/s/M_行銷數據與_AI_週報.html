M 行銷數據與 AI 週報

  • AI 軸線：用一個可重複的 prompt 範本，把雜亂數據餵給 AI，產出固定格式週報（重點摘要 / 三個變化 / 一個建議）；建立自己的「週報 prompt」。
  • 陷阱：AI 會自動填空、把缺漏的週補上看似合理的假數字——須明確要求「缺資料就標 N/A」。
  • 實作：設計並測試自己的週報 prompt 範本。
  • 小作業：繳交週報 prompt 範本 + 一份生成的範例週報。

💬 討論／分享／反思

  • 配對互評週報 prompt：兩人一組互相交換自己的週報 prompt 範本與生成的範例週報，重點看「有沒有逼 AI 對缺漏資料標 N/A」「重點摘要 / 三個變化 / 一個建議的格式有沒有被穩定遵守」，各給對方一個最該改的地方。
  • 全班一題收斂：老師收幾組的範例週報投影出來，全班一起判斷「哪些數字看起來是 AI 自己填空編出來的？怎麼一眼看出？」凝聚出一兩條辨識假數據的判斷準則。
  • 寫下個人反思：每人寫一句——「如果我每週都用這個 prompt 產週報，最可能在哪個漏斗指標上被 AI 的假數字誤導？我下次要加哪句話防住它？」
