練習 17 - 找出炎上的留言區

在本單元中，會介紹第 17 題「社群小編說有幾篇的留言區在炎上，要你從報表裡把它們找出來」從頭到尾實際跑一次的方法、跑出來的數字，以及畫出來的圖。

這一頁是做完之後對答案用的。還沒動手的話，先回 Hub - 資料分析練習案例庫 找到這一題，照「怎麼做」那一欄自己跑一次再回來。

題目

有人會這樣問你：上個月哪幾篇讀者討論最熱烈？我要挑三篇出來在社群回應，順便看看哪個版面最會引起討論。
難度 入門
組別 第 6 組：時間、存活與回頭看的陷阱
用哪張表 content_monthly_flat（L1 的 content_monthly_2024_10.csv）
對應單元 把留言變成可以算的東西（接到 情緒分類跑一次 再看它錯在哪）

方法

第一步先確認 content_id 是不是唯一、有重複就去重。第二步用 comment_cnt 直接排一次序，當作待會要推翻的對照組。第三步明講分母：算「每千名不重複使用者的留言數」＝ comment_cnt ÷ uv × 1000，並設一個最低 uv 門檻（例如 500）再排序。第四步依 section_name 與 content_type 分組比留言率，並算 comment_cnt 與 pv 的相關係數；版面之間的差距要不要當真，用一個以 uv 為曝露量的 Poisson 迴歸檢定一次。用 Python 的理由：一張 CSV、加一個欄位、排個序，pandas 從讀檔到出榜不到十行。

程式

這一題用 Python，整支程式如下。資料放在 dist/L1 與 dist/L2 兩個資料夾。

from _kmg import *
import statsmodels.api as sm
import statsmodels.formula.api as smf
from scipy import stats

r = R(17, "社群小編說有幾篇的留言區在炎上，要你從報表裡把它們找出來")
raw = flat()
f = dedupe(raw)
r.chk("列數", 1444, len(raw))
r.chk("不重複內容", 1438, len(f))
r.chk("留言數與瀏覽量的相關係數", 0.87, float(f["comment_cnt"].corr(f["pv"])), tol=0.005)
r.chk("留言最多的一篇", 12, int(f["comment_cnt"].max()))

top_c = f.sort_values(["comment_cnt", "pv"], ascending=False).head(10)
top_pv = f.sort_values("pv", ascending=False).head(10)
overlap = len(set(top_c["content_id"]) & set(top_pv["content_id"]))
r.chk("按留言數排的前十 與流量前十重疊", 4, overlap)

f = f.assign(rate=f["comment_cnt"] / f["uv"] * 1000)
top_rate = f[f["uv"] >= 500].sort_values("rate", ascending=False).head(10)
rate_pv = len(set(top_rate["content_id"]) & set(top_pv["content_id"]))
r.chk("留言率前十 與按留言數排的前十重疊", 0, len(set(top_rate["content_id"]) & set(top_c["content_id"])))
r.chk("留言率前十 與流量前十重疊", 0, rate_pv)

def grp(col):
    g = f.groupby(col).agg(c=("comment_cnt", "sum"), u=("uv", "sum"))
    g["r"] = g["c"] / g["u"] * 1000
    return g

gs, gt = grp("section_name"), grp("content_type")
r.chk("各型態留言率 最低（每千人）", 2.1, float(gt["r"].min()), tol=0.05)
r.chk("各型態留言率 最高（每千人）", 2.5, float(gt["r"].max()), tol=0.05)
r.chk("各版面留言率 最低（每千人）", 1.5, float(gs["r"].min()), tol=0.05)
r.chk("各版面留言率 最高（每千人）", 2.7, float(gs["r"].max()), tol=0.05)
r.chk("單一版面一個月的留言 最少", 14, int(gs["c"].min()))
r.chk("單一版面一個月的留言 最多", 362, int(gs["c"].max()))
m0 = smf.glm("comment_cnt ~ 1", data=f, family=sm.families.Poisson(), offset=np.log(f["uv"])).fit()
pvals = {}
for col in ("section_name", "content_type"):
    m1 = smf.glm("comment_cnt ~ C(%s)" % col, data=f, family=sm.families.Poisson(), offset=np.log(f["uv"])).fit()
    pvals[col] = float(stats.chi2.sf(2 * (m1.llf - m0.llf), m1.df_model))
r.chk("版面差異檢定 p 值", 0.40, pvals["section_name"], tol=0.005)
r.chk("型態差異檢定 p 值", 0.44, pvals["content_type"], tol=0.005)

nothr = f.sort_values("rate", ascending=False).iloc[0]
r.chk("不設門檻時榜首的讀者數", 130, int(nothr["uv"]))
r.chk("不設門檻時榜首的留言數", 1, int(nothr["comment_cnt"]))
r.chk("不設門檻時榜首的留言率", 7.7, float(nothr["rate"]), tol=0.05)
r.pit(int(nothr["uv"]) < 200, "不設 uv 門檻，留言率榜首是一則只有 %d 位讀者、%d 則留言的稿子" % (nothr["uv"], nothr["comment_cnt"]))

top_rate100 = f[f["uv"] >= 100].sort_values("rate", ascending=False).head(10)
kept = len(set(top_rate100["content_id"]) & set(top_rate["content_id"]))
r.chk("門檻 500 改成 100 後，前十名留下幾則", 0, kept)
r.sc(rate_pv < overlap and kept < 5,
     "按留言數排跟流量榜重疊 %d 則、按留言率排重疊 %d 則；門檻從 500 改成 100，前十名只留下 %d 則" % (overlap, rate_pv, kept))

fig, ax = plt.subplots(1, 2, figsize=(11, 4.5))
ax[0].scatter(f["pv"], f["comment_cnt"] + np.random.default_rng(0).uniform(-0.25, 0.25, len(f)), s=5, alpha=0.3,
              color="#999999")
ax[0].scatter(top_pv["pv"], top_pv["comment_cnt"], s=40, facecolors="none", edgecolors="#4f81bd", label="流量前十")
ax[0].scatter(top_c["pv"], top_c["comment_cnt"], s=14, color="#c0504d", label="留言數前十")
ax[0].set_xlabel("瀏覽量")
ax[0].set_ylabel("留言數（加了一點抖動避免重疊）")
ax[0].set_title("相關 0.87，但兩張前十名只重疊 4 則")
ax[0].legend()
gs = gs.sort_values("r")
err = 1.96 * np.sqrt(gs["c"]) / gs["u"] * 1000
ax[1].errorbar(gs["r"], range(len(gs)), xerr=err, fmt="o", color="#4f81bd", ecolor="#bbbbbb")
ax[1].set_yticks(range(len(gs)), gs.index, fontsize=8)
ax[1].set_xlabel("每千名讀者的留言數（橫線是 95% 區間）")
ax[1].set_title("版面之間差快兩倍，區間卻幾乎全部重疊（p=0.40）")
save_fig(fig, "ex17_comments.png")
r.save()

程式裡的 r.chk(項目, 預期值, 實算值) 是對照檢查，把入口頁寫的數字跟實際算出來的放在一起比；r.pit 記錄坑有沒有出現，r.sc 記錄自己驗那一步有沒有效。畫圖的部分在程式最後面。

程式開頭的 from _kmg import * 載入共用的讀檔、去重、換幣別與畫圖函式，內容在 練習 01 - 月會上的則數對不對 的「共用的讀檔函式」那一段。

結果

1,444 列裡只有 1,438 則不重複內容，有 6 則因為重送而出現兩列。留言數跟瀏覽量高度相關（相關係數 0.87），但按 comment_cnt 排出來的前十名，跟流量前十名只重疊 4 則——相關係數講的是整體趨勢，不保證排行榜的頭部一樣；而且留言最多的一篇也才 12 則。改成留言率之後，前十名跟按留言數排的前十名、跟流量前十名都完全沒有重疊。各型態的留言率落在每千名使用者 2.1 到 2.5 則，各版面落在 1.5 到 2.7 則；版面之間看起來差了快兩倍，但每個版面一個月只有十幾到三百多則留言，檢定版面差異 p=0.40、型態差異 p=0.44，說不出哪個版面比較會引起討論。誠實的結論是：這張表看不出炎上，因為它只留下留言的則數，沒有留言的內容。

這題的坑，實際跑的時候有沒有出現

分母混淆（KMG 埋的第三個陷阱）加上小分母洗榜。用 pv、uv 還是 sessions 當分母，會得到三份不一樣的排行榜；而且不設 uv 門檻的話，榜首會是一則只有 130 個讀者、拿到 1 則留言的稿子（每千人 7.7 則），那純粹是分母太小的運氣。還有一個更該講出來的限制：要判斷留言是正面還是負面，必須有留言原文，這份資料沒有原文，所以不可以把「留言多」寫成「炎上」。

實際跑的結果：不設 uv 門檻，留言率榜首是一則只有 130 位讀者、1 則留言的稿子。

自己驗那一步抓不抓得到錯

把你的排行榜跟「純粹按 pv 排」的排行榜並排放，數一數重疊幾則：按留言數排會跟流量榜重疊 4 則，按留言率排是 0 則，重疊越多，代表你排的越像流量而不是討論；再把最低 uv 門檻從 500 改成 100 重跑一次，如果榜單整個換人，代表你的名次是被小分母決定的，不是被讀者決定的。

實際跑的結果：按留言數排跟流量榜重疊 4 則、按留言率排重疊 0 則；門檻從 500 改成 100，前十名只留下 0 則。
