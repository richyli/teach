科技採用的經濟學模型

  • 先修：會「機率是 0 到 1」「效用 = 我從一個選項得到的價值」即可。

一條主線串起全部：個體選擇（McFadden）→ 加異質性變擴散（門檻）→ 加互動變 Bass → 加網路外部性變 lock-in → 拉到總體變 Romer/GPT。每一步都是「上一個模型多放一個經濟學假設」，學生看得到模型怎麼長出來。

個體層：採用是一個「選擇」（效用 / 期望理論）

最該補的一塊，因為它正是 conjoint 分析的理論母體。

Random Utility / Discrete Choice（McFadden, 諾貝爾經濟獎）

採用 = 比較「採用 vs 不採用」的效用，誰高選誰。第 $i$ 人對選項 $j$ 的效用：

$$U_{ij} = V_{ij} + \varepsilon_{ij}$$

$V_{ij}$ 是可觀測部分（價格、功能、易用性…），$\varepsilon_{ij}$ 是隨機誤差。選擇機率寫成 logit：

$$P_{ij} = \frac{e^{V_{ij}}}{\sum_k e^{V_{ik}}}$$

教學張力：TAM 是心理測量（量表 → SEM），McFadden 是選擇行為（選項 → logit），但兩者可以是同一個效用函數的兩種觀測方式。conjoint 研究就站在這個接縫上——用選擇資料反推「有用性」這類構念的權重。

Subjective Expected Utility / Prospect Theory（Kahneman–Tversky）

採用新科技是風險決策：期望效用 vs 價值函數 + 損失趨避。它解釋為何「現狀偏誤」讓好科技也擴散得慢——放棄舊系統的「損失」感受，是同等「獲得」的兩倍重。

自我消化：為什麼大公司明明知道新工具更好，卻常常拖很久才換？（提示：沉沒成本 + 損失趨避，不是「他們不理性」。）

群體層：擴散的經濟學版本（Bass 的近親與上位理論）

Bass 給了 S 曲線，但它把擴散當「傳染」。經濟學版本問的是：到底是什麼力量推著人一個個採用？

  • Epidemic / Logistic diffusion：Bass 的數理骨架，$\dot{N}=\beta N(M-N)$。純模仿、無創新，採用速度正比於「已採用 × 未採用」。
  • Probit / Threshold model（David, Davies）：每個採用者有異質門檻（企業規模、成本回收點不同）。科技降價時，門檻由低到高逐一被跨過——比 Bass 更「經濟學」，因為擴散是價格下降驅動，不是傳染。
  • Rank / Stock / Order effects（Karshenas & Stoneman）：擴散的總框架，把「為何有人早採用」拆成四種機制——
  • Rank（異質報酬）：不同人從科技得到的好處不同，好處大的先採用。
  • Stock（存量外溢）：採用的人越多，後採用者的好處越低（或成本越高）。
  • Order（卡位）：早採用本身有策略價值（搶先機）。
  • Epidemic（資訊擴散）：要先「知道」才能採用。

一句話對照：Bass 把所有人當成只會互相傳染的同質個體；門檻/Rank 模型承認人是不一樣的，這更貼近企業科技採用的真實。

自我消化：同一個 AI 工具，為什麼新創公司比傳統大企業早採用？用 Rank（報酬）和 Stock（轉換成本）各講一句。

網路、策略與總體（為何鎖定、要不要等、加總到哪）

網路與相容性：為何科技會「鎖定」

  • Network externalities（Katz–Shapiro, Farrell–Saloner）：效用隨採用人數上升，$U = v + \theta\, n(p)$。解釋臨界質量（critical mass）、tipping point、贏者全拿。
  • Path dependence / Lock-in（Arthur, increasing returns）：QWERTY 鍵盤、VHS 勝 Betamax。報酬遞增 → 多重均衡 → 歷史（而非優劣）決定結果。對「為何劣勢科技勝出」極有說服力。

資訊與策略：要不要「先」採用

  • Real Options（投資不可逆 + 等待價值）：採用是有 timing 的投資，不確定性高時「等待」本身有價值——解釋過度延遲。
  • Information cascades / Herding（Bikhchandani–Hirshleifer–Welch）：理性個體看別人的決策而捨棄自己的私有訊號 → 集體採用或集體不採用（可能採用到爛東西）。
  • Signaling（Spence）：採用新科技當成能力訊號（「我們很創新」）——這條線直接接信號理論。

總體 / 成長（Solow 的延伸）

  • Romer 內生成長：技術不是天上掉的「剩餘」，而是 R&D 投入的內生產物。補上 Solow 把技術當外生的最大缺口。
  • GPT（General Purpose Technology, Bresnahan–Trajtenberg）：通用技術（蒸汽、電、AI）有延遲的生產力效應，解釋 Solow 悖論——「電腦無所不在，唯獨不在生產力統計裡」，因為要等互補投資、組織重構到位。

這一堂收束成一句話：TAM/UTAUT 告訴你「為什麼一個人想用」；這些經濟模型告訴你「這些想法在市場裡會長成什麼形狀」——選擇 → 擴散 → 鎖定 → 成長。
