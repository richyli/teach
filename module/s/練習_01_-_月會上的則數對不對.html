練習 01 - 月會上的則數對不對

在本單元中，會介紹第 1 題「月會投影片上的「十月發了 1,444 則」，幫我查一下這個數字對不對」從頭到尾實際跑一次的方法、跑出來的數字，以及畫出來的圖。

這一頁是做完之後對答案用的。還沒動手的話，先回 Hub - 資料分析練習案例庫 找到這一題，照「怎麼做」那一欄自己跑一次再回來。

題目

有人會這樣問你：總編輯明天月會要說「十月我們發了 1,444 則報導、拿到 92 萬次瀏覽」，這兩個數字可以直接上投影片嗎？
難度 入門
組別 第 1 組：先把一張表讀對
用哪張表 content_monthly_flat（L1 的 content_monthly_2024_10.csv）
對應單元 第一次讓 AI 讀一張表

方法

先讀資料字典，把這張表的主鍵找出來（content_id ＋ stat_month），再用 pandas 的 duplicated() 檢查主鍵是不是真的唯一；發現不唯一就照 ingest_ts（入庫時間）取最新那一列，然後重新算則數與瀏覽量總和。用 Python，因為「檢查主鍵有沒有重複」＋「按指定欄位去重」在 pandas 只要兩行，同一件事在 Excel 要一路拉公式比對才看得出來是哪幾列重覆。

程式

這一題用 Python，整支程式如下。資料放在 dist/L1 與 dist/L2 兩個資料夾。

from _kmg import *

r = R(1, "月會投影片上的「十月發了 1,444 則」，幫我查一下這個數字對不對")
df = flat()
r.chk("列數", 1444, len(df))
r.chk("不重複 content_id", 1438, df["content_id"].nunique())
dup_before = int(df.duplicated(["content_id", "stat_month"]).sum())
r.chk("主鍵重複列數", 6, dup_before)

dd = dedupe(df)
removed = df.loc[~df.index.isin(dd.index)]
r.chk("去重後則數", 1438, len(dd))
r.chk("去重後總瀏覽量", 918470, int(dd["pv"].sum()))
r.chk("被多算的瀏覽量", 2266, int(df["pv"].sum() - dd["pv"].sum()))
pair = df[df.duplicated(["content_id", "stat_month"], keep=False)].drop(columns="ingest_ts")
r.chk("重複列除 ingest_ts 外完全相同（列數）", 12, int(pair.duplicated(keep=False).sum()))

naive = df.drop_duplicates()
r.pit(len(naive) == len(df), "整列 drop_duplicates() 一列都沒刪掉（刪掉 %d 列），因為重送的兩列 ingest_ts 不一樣" % (
    len(df) - len(naive)))

dup_after = int(dd.duplicated(["content_id", "stat_month"]).sum())
gap = int(df["pv"].sum() - dd["pv"].sum())
r.sc(dup_before == 6 and dup_after == 0 and gap == int(removed["pv"].sum()),
     "主鍵重複從 %d 列變成 %d 列；總瀏覽量少了 %d，剛好等於被刪掉那幾列的瀏覽量加總 %d" % (
         dup_before, dup_after, gap, int(removed["pv"].sum())))

rm = removed.sort_values("pv")
fig, ax = plt.subplots(figsize=(7, 3.6))
ax.barh(rm["content_id"], rm["pv"], color="#c0504d")
for y, v in enumerate(rm["pv"]):
    ax.text(v, y, " %d" % v, va="center", fontsize=9)
ax.set_xlabel("被重複計入的瀏覽量")
ax.set_title("重送的 6 則內容：各自的瀏覽量被算了兩次，合計多算 %s 次" % format(gap, ","))
save_fig(fig, "ex01_duplicates.png")
r.save()

程式裡的 r.chk(項目, 預期值, 實算值) 是對照檢查，把入口頁寫的數字跟實際算出來的放在一起比；r.pit 記錄坑有沒有出現，r.sc 記錄自己驗那一步有沒有效。畫圖的部分在程式最後面。

共用的讀檔函式

每一支 Python 程式開頭的 from _kmg import * 載入的是下面這一支：讀檔、去重、換幣別、算 entropy、存圖，以及記錄對照檢查的 R 類別。

"""練習實跑的共用載入與記錄工具。每一題的腳本都 from _kmg import *。"""
import json
from pathlib import Path

import matplotlib
import numpy as np
import pandas as pd

matplotlib.use("Agg")
import matplotlib.pyplot as plt  # noqa: E402

HERE = Path(__file__).resolve().parent
ROOT = HERE.parents[1]                     # projects/kmg_data_universe
L1, L2 = ROOT / "dist" / "L1", ROOT / "dist" / "L2"
RES = HERE / "results"
RES.mkdir(exist_ok=True)
RATE = 31.5                                # 1 USD = 31.5 TWD（練習題指定的匯率）

# 圖上的中文：Windows 用正黑體，其他系統退回 Noto Sans TC
plt.rcParams["font.family"] = ["Microsoft JhengHei", "Noto Sans TC", "sans-serif"]
plt.rcParams["axes.unicode_minus"] = False
plt.rcParams["axes.spines.top"] = False
plt.rcParams["axes.spines.right"] = False

def flat():
    return pd.read_csv(L1 / "content_monthly_2024_10.csv", encoding="utf-8-sig",
                       parse_dates=["publish_at", "ingest_ts"])

def ad():
    return pd.read_csv(L1 / "ad_daily_2024_10.csv", encoding="utf-8-sig", parse_dates=["stat_date"])

def l2(name, **kw):
    return pd.read_csv(L2 / name, encoding="utf-8-sig", **kw)

def dedupe(df):
    """主鍵 content_id＋stat_month 去重，重送的列取入庫時間最新的那一列。"""
    return df.sort_values("ingest_ts").drop_duplicates(["content_id", "stat_month"], keep="last")

def twd(a):
    return np.where(a["currency"] == "USD", a["revenue"] * RATE, a["revenue"])

def entropy_bits(p):
    p = np.asarray(p, dtype=float)
    p = p[p > 0] / p[p > 0].sum()
    return float(-(p * np.log2(p)).sum())

def save_fig(fig, name):
    fig.tight_layout()
    fig.savefig(RES / name, dpi=130)
    plt.close(fig)

def _py(o):
    return o.item() if hasattr(o, "item") else str(o)

class R:
    """一題的結果：數字比對、坑有沒有出現、自驗有沒有用。

    suffix 給 R 題的 Python 補充腳本用（畫圖與課堂概念的數字），存成 exNN_py.json，
    不會蓋掉 R 自己輸出的 exNN.tsv。
    """

    def __init__(self, no, title, suffix=""):
        self.suffix = suffix
        self.d = {"no": no, "title": title, "checks": [], "pitfall": None, "selfcheck": None, "notes": []}

    def chk(self, name, expected, actual, tol=None, rel=None):
        if tol is None and rel is None:
            ok = expected == actual
        elif rel is not None:
            ok = abs(float(actual) - float(expected)) <= abs(float(expected)) * rel
        else:
            ok = abs(float(actual) - float(expected)) <= tol
        if isinstance(actual, float):
            actual = round(actual, 4)
        self.d["checks"].append({"name": name, "expected": expected, "actual": actual, "ok": bool(ok)})

    def pit(self, observed, detail):
        self.d["pitfall"] = {"observed": bool(observed), "detail": detail}

    def sc(self, works, detail):
        self.d["selfcheck"] = {"works": bool(works), "detail": detail}

    def note(self, text):
        self.d["notes"].append(text)

    def save(self):
        path = RES / ("ex%02d%s.json" % (self.d["no"], self.suffix))
        path.write_text(json.dumps(self.d, ensure_ascii=False, indent=1, default=_py), encoding="utf-8")
        bad = [c["name"] for c in self.d["checks"] if not c["ok"]]
        p = self.d["pitfall"] and self.d["pitfall"]["observed"]
        s = self.d["selfcheck"] and self.d["selfcheck"]["works"]
        print("ex%02d%s  數字 %d/%d 相符 | 坑出現 %s | 自驗有效 %s | 不符：%s" % (
            self.d["no"], self.suffix, len(self.d["checks"]) - len(bad), len(self.d["checks"]), p, s,
            "；".join(bad) or "無"))

結果

表裡有 1,444 列，但只有 1,438 個不同的 content_id——有 6 則內容因為報表重送各出現兩次，兩列除了 ingest_ts 以外一模一樣。去重後正確答案是 1,438 則、918,470 次瀏覽；被多算掉的 2,266 次瀏覽，剛好等於那 6 列的 pv 加總。誤差只有 0.25% 看似無傷，但「一列就是一則」這句話是錯的，之後任何按記者、按版面算則數的報表都會跟著錯。

圖表

每一條是一則被重送的內容，長度是它的瀏覽量。這六則各被算了兩次，加起來就是總瀏覽量多出來的 2,266 次。

這題的坑，實際跑的時候有沒有出現

對應 KMG 埋的「重複列」陷阱。最容易踩的不是忘記去重，而是直接用 df.drop_duplicates()——它比對的是整列，而重覆的那兩列 ingest_ts 不一樣，所以一列都刪不掉，程式不會報錯也不會有警告，你會得到「這張表沒有重複」的錯誤結論。要寫成 drop_duplicates(subset=['content_id','stat_month']) 才有用。

實際跑的結果：整列 drop_duplicates() 一列都沒刪掉（刪掉 0 列），因為重送的兩列 ingest_ts 不一樣。

自己驗那一步抓不抓得到錯

去重前後各跑一次 df.duplicated(subset=['content_id','stat_month']).sum()，數字要從 6 變成 0；再確認總瀏覽量的差額剛好等於被刪掉那幾列的 pv 加總（2,266），對不起來就代表刪錯列了。

實際跑的結果：主鍵重複從 6 列變成 0 列；總瀏覽量少了 2266，剛好等於被刪掉那幾列的瀏覽量加總 2266。
