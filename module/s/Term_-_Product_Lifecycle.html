Product Lifecycle｜產品生命週期

Product Lifecycle

The full loop a product runs through — research, documents, build, launch, metrics — where every stage owes the next one something concrete.

一個產品從研究、寫文件、做出來、上線到看數字的完整循環，每一階都要交一樣東西給下一階。

What this term means｜這個詞在說什麼

This course uses five stages: research → MRD → PRD → launch → metrics, and the metrics become the next round's research question.

What matters is not the names but the artefacts: a stage that produced nothing has not happened, however many meetings it consumed. Skipping a handover does not save time; it moves the cost into the stage where fixing it is most expensive.

這門課用的五階是：研究 → MRD → PRD → 上線 → 指標，而指標又回頭變成下一輪的研究問題。

關鍵不在階段名稱，在交付物：一個沒有產出任何東西的階段，不管開了幾次會，都等於沒有發生。跳過交接不會省時間，只會把成本移到後面更貴的階段。

Common misconceptions｜常見誤解

  • Memorising it as a flow chart. It is a set of handovers, not a conveyor belt.

  • Confusing it with the user journey — that is the user's process, not the product's.

  • 把它當成流程圖背下來。它是一組交接關係，不是一條輸送帶。

  • 與使用者旅程混用——那是使用者的過程，不是產品的過程。
