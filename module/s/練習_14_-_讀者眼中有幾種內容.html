練習 14 - 讀者眼中有幾種內容

在本單元中，會介紹第 14 題「總編要一張表：這個月一千多則內容，讀者眼中到底是幾種？」從頭到尾實際跑一次的方法、跑出來的數字，以及畫出來的圖。

這一頁是做完之後對答案用的。還沒動手的話，先回 Hub - 資料分析練習案例庫 找到這一題，照「怎麼做」那一欄自己跑一次再回來。

題目

有人會這樣問你：我們每個月發一千多則，後台只分新聞、深度、影音、Podcast 四種。但那是我們自己編的分類，讀者的行為真的也分成四種嗎？其中哪一群是真的在幫我們賣訂閱的？
難度 入門
組別 第 5 組：沒有標籤的時候怎麼看出結構
用哪張表 content_monthly_flat（L1 的 content_monthly_2024_10.csv）
對應單元 沒有標籤的時候怎麼分群

方法

K-means 分群。不要拿 pv、uv、sessions 這種量體欄位直接分，改用每一則自己的比率當特徵：每次瀏覽的平均停留秒數（dwell_sec_total / pv）、跳出率（bounce_sessions / sessions）、每千次瀏覽的分享數與留言數、撞牆率（paywall_hit_cnt / sessions）、撞牆後的轉換率（conversion_cnt / paywall_hit_cnt）。六個特徵先做標準化，再跑 k = 2 到 6（KMeans 的 n_init=10、random_state=42），把每個 k 的 silhouette 都印出來，再決定要幾群。用 Python 的理由：標準化、KMeans、silhouette 在 scikit-learn 裡各一行就有，你的力氣可以全花在挑特徵跟解釋分群上。

程式

這一題用 Python，整支程式如下。資料放在 dist/L1 與 dist/L2 兩個資料夾。

from math import lgamma, log

from _kmg import *
from sklearn.cluster import KMeans
from sklearn.metrics import adjusted_rand_score, silhouette_score
from sklearn.preprocessing import StandardScaler

r = R(14, "總編要一張表：這個月一千多則內容，讀者眼中到底是幾種？")
f = dedupe(flat()).reset_index(drop=True)
F = pd.DataFrame({
    "dwell_per_pv": f["dwell_sec_total"] / f["pv"],
    "bounce": f["bounce_sessions"] / f["sessions"],
    "share_k": f["share_cnt"] / f["pv"] * 1000,
    "comment_k": f["comment_cnt"] / f["pv"] * 1000,
    "hit_rate": f["paywall_hit_cnt"] / f["sessions"],
    "conv_hit": (f["conversion_cnt"] / f["paywall_hit_cnt"]).fillna(0),
}).replace([np.inf, -np.inf], 0).fillna(0)
Z = StandardScaler().fit_transform(F)
sil = {}
for k in range(2, 7):
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(Z)
    sil[k] = float(silhouette_score(Z, km.labels_))
r.note("各 k 的 silhouette：" + "、".join("k=%d %.3f" % kv for kv in sil.items()))
r.chk("silhouette（k=4）", 0.24, sil[4], tol=0.005)
r.chk("silhouette 最高的 k", 2, max(sil, key=sil.get))
r.chk("silhouette 最高值", 0.27, max(sil.values()), tol=0.005)
r.chk("k=2 到 6 的 silhouette 最低值", 0.24, min(sil.values()), tol=0.005)

km = KMeans(n_clusters=4, n_init=10, random_state=42).fit(Z)
f["cl"] = km.labels_
prof = F.assign(pv=f["pv"], cl=f["cl"]).groupby("cl").agg(
    dwell=("dwell_per_pv", "mean"), hit=("hit_rate", "mean"), bounce=("bounce", "mean"),
    conv=("conv_hit", "mean"), pvmed=("pv", "median"), n=("pv", "size"))
paywalled = f.groupby("cl")["is_paywalled"].mean()
av, nw, hi, deep = prof["dwell"].idxmax(), prof["dwell"].idxmin(), prof["hit"].idxmax(), prof["pvmed"].idxmin()
r.chk("四種性格各落在不同群", 4, len({av, nw, hi, deep}))
r.chk("影音群每次瀏覽停留（秒）", 135, float(prof.loc[av, "dwell"]), tol=0.5)
r.chk("影音群付費牆比例", 0.0, float(paywalled[av]), tol=0.01)
r.chk("即時新聞群每次瀏覽停留（秒）", 23, float(prof.loc[nw, "dwell"]), tol=0.5)
r.chk("付費新聞群撞牆率", 0.35, float(prof.loc[hi, "hit"]), tol=0.005)
r.chk("影音群撞牆率", 0.02, float(prof.loc[av, "hit"]), tol=0.005)
r.chk("即時新聞群撞牆率", 0.02, float(prof.loc[nw, "hit"]), tol=0.005)
r.chk("深度群撞牆率", 0.16, float(prof.loc[deep, "hit"]), tol=0.005)
r.chk("深度群瀏覽量中位數", 229, float(prof.loc[deep, "pvmed"]), tol=1)
others = prof.drop(deep)
r.chk("其他三群瀏覽量中位數 最低", 448, float(others["pvmed"].min()), tol=1)
r.chk("其他三群瀏覽量中位數 最高", 493, float(others["pvmed"].max()), tol=1)
r.chk("深度群跳出率", 0.46, float(prof.loc[deep, "bounce"]), tol=0.005)
r.chk("深度群撞牆轉換率", 0.345, float(prof.loc[deep, "conv"]), tol=0.003)
r.chk("其他三群撞牆轉換率 最低", 0.16, float(others["conv"].min()), tol=0.005)
r.chk("其他三群撞牆轉換率 最高", 0.21, float(others["conv"].max()), tol=0.005)
r.chk("深度群跳出率是四群最低", True, bool(prof["bounce"].idxmin() == deep))
r.chk("深度群撞牆轉換率是四群最高", True, bool(prof["conv"].idxmax() == deep))

# 課堂概念：搜尋空間。1,438 則分成 4 群的分法約 4^n / 4!；只起跑一次會停在哪裡
n = len(f)
log10_ways = (n * log(4) - lgamma(5)) / log(10)
r.chk("分成 4 群的分法（10 的幾次方）", 864, int(log10_ways))
runs = [KMeans(n_clusters=4, n_init=1, random_state=s).fit(Z) for s in range(20)]
ari = [adjusted_rand_score(km.labels_, m.labels_) for m in runs]
inertia = [m.inertia_ for m in runs]
r.chk("只起跑一次 20 個種子 inertia 最低", 5345, float(min(inertia)), tol=1)
r.chk("只起跑一次 20 個種子 inertia 最高", 5642, float(max(inertia)), tol=1)
r.chk("跟最佳解的一致度 ARI 最低", 0.43, float(min(ari)), tol=0.005)
r.chk("跟最佳解分群完全相同的次數", 0, int(sum(a == 1.0 for a in ari)))
r.note("只起跑一次時，20 個種子跟最佳解的 ARI 最高是 %.4f" % max(ari))

# 課堂概念：entropy。知道群別之後，內容型態還剩多少不確定性
H = entropy_bits(f["content_type"].value_counts())
per = {int(c): entropy_bits(g.value_counts()) for c, g in f.groupby("cl")["content_type"]}
Hc = sum(float((f["cl"] == c).mean()) * h for c, h in per.items())
r.chk("內容型態 entropy（bits）", 1.58, H, tol=0.005)
r.chk("知道群別後剩的 entropy（bits）", 0.63, Hc, tol=0.005)
r.chk("分群帶走的比例", 0.60, (H - Hc) / H, tol=0.005)
r.chk("最純那一群的 entropy（bits）", 0.27, min(per.values()), tol=0.005)
r.chk("最混那一群的 entropy（bits）", 1.28, max(per.values()), tol=0.005)

Fr = F.assign(dwell_total=f["dwell_sec_total"], conv_raw=f["conversion_cnt"])
lab_raw = KMeans(n_clusters=4, n_init=10, random_state=42).fit_predict(Fr)
x = f["dwell_sec_total"]
eta2 = 1 - ((x - x.groupby(lab_raw).transform("mean")) ** 2).sum() / ((x - x.mean()) ** 2).sum()
r.pit(eta2 > 0.8, "不標準化又放進停留總秒數時，分出來的四群可以解釋停留總秒數差異的 %.0f%%，分到的是量體不是性格" % (eta2 * 100))
NAME = {av: "影音群", nw: "即時新聞群", hi: "付費新聞群", deep: "深度報導群"}
ctab = pd.crosstab(f["cl"].map(NAME), f["content_type"])
r.sc(len(set(NAME.values())) == 4, "四群都命名得出來；交叉表：" + "；".join(
    "%s %s" % (k, "、".join("%s %d" % (c, v) for c, v in row.items() if v)) for k, row in ctab.iterrows()))

LAB = {"dwell_per_pv": "每次瀏覽停留", "bounce": "跳出率", "share_k": "每千次分享", "comment_k": "每千次留言",
       "hit_rate": "撞牆率", "conv_hit": "撞牆後轉換率"}
centers = pd.DataFrame(km.cluster_centers_, columns=[LAB[c] for c in F.columns]).rename(index=NAME)
centers = centers.loc"影音群", "即時新聞群", "付費新聞群", "深度報導群"
fig, ax = plt.subplots(1, 2, figsize=(11, 4), gridspec_kw={"width_ratios": [3, 2]})
im = ax[0].imshow(centers.values, cmap="RdBu_r", vmin=-2, vmax=2)
for i in range(centers.shape[0]):
    for j in range(centers.shape[1]):
        ax[0].text(j, i, "%.1f" % centers.values[i, j], ha="center", va="center", fontsize=9)
ax[0].set_xticks(range(6), centers.columns, rotation=30)
ax[0].set_yticks(range(4), ["%s（%d 則）" % (nm, (f["cl"].map(NAME) == nm).sum()) for nm in centers.index])
ax[0].set_title("四群的輪廓（標準化後的群中心，0＝全站平均）")
fig.colorbar(im, ax=ax[0], shrink=0.8)
ax[1].plot(list(sil), list(sil.values()), marker="o")
ax[1].set_xlabel("群數 k")
ax[1].set_ylabel("silhouette")
ax[1].set_ylim(0.2, 0.3)
ax[1].set_title("silhouette 挑不出 k=4，k=2 到 6 都差不多")
save_fig(fig, "ex14_clusters.png")
r.save()

程式裡的 r.chk(項目, 預期值, 實算值) 是對照檢查，把入口頁寫的數字跟實際算出來的放在一起比；r.pit 記錄坑有沒有出現，r.sc 記錄自己驗那一步有沒有效。畫圖的部分在程式最後面。

程式開頭的 from _kmg import * 載入共用的讀檔、去重、換幣別與畫圖函式，內容在 練習 01 - 月會上的則數對不對 的「共用的讀檔函式」那一段。

結果

k=4 會分出四群，而且四群都講得出一句話：一群平均每次瀏覽停留 135 秒、完全不在付費牆後（影音與 Podcast）；一群只停留 23 秒（即時新聞）；一群撞牆率 0.35（付費牆裡的新聞），影音群與即時新聞群都只有 0.02；最後一群瀏覽量中位數只有 229（其他三群在 448 到 493），撞牆率 0.16，跳出率卻最低（0.46）、撞牆後轉換率最高（0.345，其他三群 0.16 到 0.21）——那就是深度報導群，它不紅，但它是賣訂閱的那一群，這就是回答總編那句問話的答案。一併要注意 k=4 的 silhouette 只有 0.24，最高的反而是 k=2（0.27），k=2 到 6 全部擠在 0.24 到 0.27 之間：選四群是因為四群都講得出一句話，不是指標替你挑的。這四群是好用的標籤，不是資料裡天然存在的界線。

左圖是四群的群中心，數字是標準化後離全站平均幾個標準差，紅色高於平均、藍色低於平均。右圖是 k=2 到 6 的 silhouette，最高的是 k=2，不是 k=4。

這題的坑，實際跑的時候有沒有出現

KMG 埋的「分母混淆」陷阱：pv、uv、sessions、paywall_hit 是四個不同的分母，講的是四件事，又彼此高度相關。如果原封不動一起丟進 K-means 而且沒做標準化，dwell_sec_total 動輒十萬、conversion_cnt 只有個位數，兩點之間的距離幾乎完全由停留秒數決定，跑出來的四群其實只是「大則、中則、小則」。還有一個小坑：content_monthly_flat 有 1444 列但只有 1438 則內容，有 6 列是重送的（同一個 content_id，只有 ingest_ts 不一樣），沒先去重那幾則會被算兩次。

實際跑的結果：不標準化又放進停留總秒數時，分出來的四群可以解釋停留總秒數差異的 87%，分到的是量體不是性格。

自己驗那一步抓不抓得到錯

把分群結果跟 content_type、is_paywalled 拉一張交叉表，然後強迫自己用一句不含數字的中文替每一群命名（例如「靠停留時間換廣告的影音群」）；只要有一群你只講得出「這群數字比較大」，就是分到量體不是分到性格，回頭檢查有沒有標準化。

實際跑的結果：四群都命名得出來；交叉表：付費新聞群 feature 21、news 187；即時新聞群 feature 3、news 660、video 25；影音群 feature 21、podcast 156、video 153；深度報導群 feature 169、news 27、podcast 3、video 13。

連到課堂概念

entropy

內容型態本身有 1.58 bits 的不確定性，知道一則內容落在哪一群之後剩 0.63 bits，分群帶走了 60%。四群裡最純的一群只剩 0.27 bits，最混的一群還有 1.28 bits，交叉表要先看那一群。見 Entropy 與 Shannon 資訊理論
