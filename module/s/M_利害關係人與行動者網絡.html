利害關係人與行動者網絡

  • 理論：Actor-Network Theory（Latour; Callon，主）——利害關係人含非人類行動者，ANT 給出 mapping 語彙；輔以 Service-Dominant Logic（關係＝價值共創而非零和）、Boundary Object Theory。
  • Flip Exercise｜Actant Mapping：各組畫出自己產品的 ANT 圖，須含 ≥3 個非人類 actant（資料集、API、模型供應商、監管者）；其他組公開挑戰「你漏了哪個 actant？」
  • 小作業：繳交 ANT 圖 + 被挑戰後補上的 actant。
  • 案例：Opus 4.7 Claude Code Hackathon「領域知識才是護城河」——MaestrIA 的診斷規則訪談自當技師的父親、ARIA 編碼資深工程師直覺；有護城河的不是 AI 寫的程式，而是來自人（利害關係人/專家）的領域知識。

💬 討論／分享／反思

  • 兩組互評 ANT 圖：相鄰兩組交換剛畫好的 actant mapping，互相挑「你把哪個非人類 actant 當成單純工具、其實它會反過來『管你』？」（例如 API 改版、模型供應商漲價、監管者一句話讓你整個功能下架）。各自圈出對方圖上「權力被低估」的那個 actant。
  • 一起收斂一題：把各組挑出來的 actant 攤在白板上，全班投票選出「這學期專案裡最該提早經營、但大家最常忘記」的那個利害關係人或非人類行動者，並用 Power/interest grid 說它該落在哪一格、對應的 RACI 角色是什麼。
  • 寫下個人反思：每人一句寫在作業欄——「我原本把＿＿＿當背景，現在發現它其實是會左右成敗的 actant，下一步我要對它做的『向上／橫向管理』動作是＿＿＿」。
