Claude Code Onboarding

This unit covers what makes an agent different from a chatbot, getting Claude Code installed and running one structured instruction on real work, and knowing when to let it run and when to take over.

🎯 Learning objectives

The point is not to learn to code. It is to get an agent that actually does things running on your own machine, on work you actually have.

# What you will be able to do The real problem it lets you answer
1 Tell apart agent, chatbot, and workflow, and say why Claude Code is an agent Why is Claude Code not just "a smarter chat box"? Because it reads your files, writes files, runs commands, and makes judgement calls while doing it.
2 Install it and give one well-structured instruction — context, task, output format — on a piece of real work Why does the same instruction produce something bad for me and something good for someone else? The quality of the output depends on how you ask. You do the instructing and the checking; it does the executing.
3 Judge, within a single task, which step to let it run and which step to brake on and take over yourself Can someone who cannot code actually use this? Break down one real task and you find the deciding factor is not technical skill, it is knowing when to let go and when to hold the line.

Hands-on

  1. Install Claude Code and get it running
  2. Give it one instruction in three parts — context, task, output format — on a real piece of your own work
  3. Mark one thing it did well and one thing you had to step in and fix

✍️ Take-home task

Take one piece of real work through Claude Code. Record one thing it got right and one thing it got wrong, and write a sentence on how you would change the prompt next time.

💬 Discussion and reflection

Pair review

Look at each other's output.

  1. Point at one place the AI genuinely helped
  2. Point at one place that needed you to intervene
  3. Say which of the three parts of the instruction — context, task, format — was weakest

Individual reflection

Write one sentence to keep: "If this were my weekly work, would I use it regularly? What stops me — the interface, trust, or not knowing what it can do?"
