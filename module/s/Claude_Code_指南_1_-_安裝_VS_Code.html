Claude Code 指南 1｜安裝 VS Code

在本單元中，會介紹怎麼裝好 VS Code、怎麼用它開一個資料夾，以及為什麼「你開哪個資料夾」是接下來所有操作裡最關鍵的一步。

VS Code 是工作台，不是寫程式的門檻

VS Code 是微軟出的免費編輯器，本質上是一個「能打開一整個資料夾、同時編輯很多檔案」的工具。它是程式設計師的主力工具，但你用它的理由跟他們不同：你需要一個地方，可以同時看到你的檔案、看到 AI 打算怎麼改、然後一處一處點頭。

Claude Code 不裝 VS Code 也能跑，直接在 PowerShell 或終端機打指令就行。但在 VS Code 裡跑多三件事，而這三件都跟「驗收」有關：

多出來的東西 它讓你做什麼
並排比對 它要改你的檔案時左右對照顯示，你點核准才生效。法規比對、公文修訂這類工作會用爆這個畫面
選取即上下文 你在編輯器裡反白一段文字，它就看得到你在講哪一段
@ 帶入檔案 在輸入框打 @ 接檔名，那份檔就進入這次對話

下載與安裝

Windows

  1. 開 <https://code.visualstudio.com>，點藍色的下載鍵，它會自動偵測你的系統。
  2. 執行下載回來的安裝檔。
  3. 安裝選項頁面，把這兩項勾起來：
  4. 加入 PATH（Add to PATH）
  5. 將「以 Code 開啟」加入檔案總管的右鍵選單
  6. 其餘保持預設，按下一步到完成。

macOS

  1. 開 <https://code.visualstudio.com> 下載 macOS 版，解壓縮後得到 Visual Studio Code 這個 app。
  2. 把它拖進「應用程式」資料夾再開啟，不要直接從下載資料夾開。
  3. 開啟後按 Cmd+Shift+P，輸入 shell command，選「Install 'code' command in PATH」。

版本要求是 1.94.0 以上，2026 年之後下載的版本都符合。要確認的話，Windows 走「說明 → 關於」，Mac 走「Code → 關於 Visual Studio Code」。

第一次開啟先做三件事

  1. 介面語言換成中文：按 Ctrl+Shift+X（Mac 是 Cmd+Shift+X）打開擴充套件，搜尋 Chinese，安裝「Chinese (Traditional) Language Pack」，然後重新啟動。
  2. 字放大：Ctrl+, 開設定，搜尋 font size，把編輯器字體調到 16 以上。等一下要盯著畫面比對改動，小字很傷眼。
  3. 認得整合終端機：按 Ctrl+`（那個在 Esc 下面、數字 1 左邊的鍵）會從下方叫出一個黑色區塊，那就是終端機。指南 2 會用到它。

開哪個資料夾，決定它看得到什麼

這是全套操作裡最容易出錯、後果也最直接的一件事：Claude Code 只看得到你開啟的那個資料夾底下的東西。你開了桌面，它就看得到整個桌面；你開了某個專案資料夾，它就只看得到那個專案。

所以請先替這門課建一個乾淨的資料夾，不要一上來就對著整個「文件」或整顆 D 槽動手。

  1. 在你習慣的位置建一個資料夾，例如 D:\AI練習 或 ~/AI練習。
  2. 回到 VS Code，選「檔案 → 開啟資料夾」，選這個資料夾。
  3. 左側會出現這個資料夾的檔案清單，這就是它的視野範圍。
  4. 把你這週要處理的那份真實工作檔（逐字稿、報告、一封長信）複製一份進來。

用複製進來的檔，不要直接開原始檔案所在的資料夾。第一週你還在建立信任，用副本操作，改壞了也不痛。

資料夾怎麼分，之後就決定守則怎麼寫

先想一下你之後真正要用的樣子。一個部門常見的分法是：

編輯室AI/
├── 逐字稿/
├── 新聞稿/
├── 法規比對/
└── 已發布/        ← 之後會在守則裡寫明：不可更動

分好資料夾的價值在指南 4 會兌現：你可以在守則裡寫「不可動 已發布/ 資料夾」，這種規則只有在資料夾本身分得清楚時才寫得出來。

檢查清單

做完這份，你應該可以打勾：

  • [ ] VS Code 裝好，開得起來
  • [ ] 用 Ctrl+` 叫得出終端機
  • [ ] 已經用「開啟資料夾」開了一個乾淨的練習資料夾
  • [ ] 左側檔案清單看得到你複製進去的那份真實工作檔
  • [ ] 你講得出「它只看得到我開的那個資料夾」這句話
