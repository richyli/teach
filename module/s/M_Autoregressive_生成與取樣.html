M Autoregressive 生成與取樣

  • 一句話：LLM 是逐 token、一次一個、回頭看自己剛寫的來生成（autoregressive）。每一步它都從一個機率分布裡「抽」下一個 token——抽的方式（取樣）決定它有多穩、多有創意、多容易跑掉。

核心

Autoregressive = 自我回歸：寫第 5 個 token 時，它看的是「題目 + 自己剛寫的前 4 個」。它把自己的輸出當成下一步的輸入。 整段話是一個 token 接一個 token 滾出來的。

取樣（sampling）= 怎麼從機率分布裡抽：每一步模型給出「下一個 token 的機率分布」，然後—— - Temperature 低（接近 0）：幾乎只挑機率最高的 → 穩定、可重複、但呆板（低 entropy）。 - Temperature 高：容許低機率選項出頭 → 多樣、有創意、但也更容易跑題或胡說（高 entropy）。 - Top-p / Top-k：只在「最可能的一小撮」裡抽，砍掉長尾爛選項。

連回 M Entropy 與 Shannon 資訊理論：temperature 就是在手動調輸出分布的 entropy。連回 M AI 圖像偏見與資訊熵：低溫把刻板印象鎖死，正是同一回事。

為什麼這對 looping engineering 致命： 1. 誤差會累積（雪球效應）：因為它把自己的輸出餵回自己，早一步的小錯會被當成既定事實，越滾越偏。多步 agent loop 尤其明顯——第 1 步歪一點，第 10 步可能完全跑掉。 2. 沒有「回頭改」：標準生成一旦寫出某 token 就不收回。Looping/agent 設計要靠外部機制（檢查、重試、把錯誤回饋進下一輪）來補這個缺陷。 3. 隨機性要管理：同一個 prompt 跑兩次結果不同，是取樣的隨機。要可重現就壓低溫度；要探索就調高——這是 loop 設計的旋鈕。

💬 互動

  • 一起想一題：一個 10 步的 agent loop，第一步資訊就抓錯了，後面會怎樣？該在哪裡放「煞車」？（連回累積誤差）

  • 反思：「AI 會『一本正經接著錯下去』，是因為它把自己剛寫的當真——我要在 loop 裡幫它設檢查點。」
