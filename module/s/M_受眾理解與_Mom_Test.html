受眾理解與 Mom Test

  • 理論：Uses and Gratifications（主）；輔以 Para-social Interaction、Algorithmic Imaginaries（Bucher）——使用者「以為」演算法在做什麼，與它實際做什麼一樣重要。
  • Flip Exercise｜Mom Test Live：兩人一組，依《The Mom Test》規則（Rob Fitzpatrick：不問意見、不假設、不推銷）互訪最近一次內容消費經驗；全班檢討哪些問題挖到真實行為、哪些只是討拍。為 W13 的 AI-persona 焦點團體鋪對照。
  • 小作業：繳交 3 條「挖到真實行為」與 3 條「無效問題」對照。

💬 討論／分享／反思

  • 配對互評：跟旁邊同學交換剛剛 Mom Test 訪談裡的問句，互相挑出「對方哪一題其實是在誘導 / 在討拍」，並幫對方改寫成一個不問意見、只問過去具體行為的版本。
  • 一起收斂一題：老師抽幾組分享，一起回答「為什麼『你會不會用？』這種未來假設問題挖不到真實行為？」收斂到「人對自己未來行為的預測不可靠，只有過去做過的事才算數」。
  • 寫下個人反思：寫一句——下次我要訪問我的目標受眾（或做 persona）時，我會把哪一個習慣性的爛問題換掉？換成什麼？
