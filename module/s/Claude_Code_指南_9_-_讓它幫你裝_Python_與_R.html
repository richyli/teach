Claude Code 指南 9｜讓它幫你裝 Python 與 R

在本單元中，會介紹怎麼讓 Claude Code 把這台電腦的分析環境裝起來、怎麼確認它真的裝好了，以及卡住的時候要怎麼把問題描述清楚。

這一份接在 指南 8 後面。前面八份讓你把 Claude Code 跑起來、會下指令、懂權限模式；從這一份開始，它要幫你處理的不再是文字，而是資料。

這份指南不會告訴你安裝指令

安裝指令由軟體公司維護，改版很快。今天抄下來的指令，明年就對不上畫面了。不會過期的是另外兩件事：你要它交出什麼，以及你怎麼確認它真的做到了。

所以下面給你的是一段提示，和一張驗收清單。

動手之前先照三條規定擺好位置

這三條不是原理，是經驗。照做只花兩分鐘，可以省掉初學者最常撞的三種錯誤。

規定 怎麼做 不照做會發生什麼
虛擬環境放短路徑 Windows 放 C:/cvenv，Mac 放家目錄底下的 cvenv 套件裝到一半失敗，而且失敗訊息完全看不懂
專案資料夾放短路徑 Windows 放 C:/kmg，Mac 放家目錄底下的 kmg 雲端同步會把檔案鎖住，程式讀不到
路徑不要有中文和空白 資料夾名字用英文小寫 有些工具會在中文路徑上直接爆掉

特別提醒：不要把專案放在桌面，也不要放在 OneDrive、iCloud、Google 雲端硬碟同步的資料夾裡。這三個地方是災難的溫床。

把這段整段貼給它

先新開一個資料夾（照上面的規定），在裡面啟動 Claude Code，然後貼這段：

我要做這門課的資料分析，會用到 Python 和 R，我不會寫程式。請依序完成以下五件事，每完成一件就告訴我結果： 一，偵測我的作業系統、Python 和 R 的位置與版本，如果找不到就告訴我還沒裝。 二，把偵測結果寫成這個資料夾裡的 ENVIRONMENT.md，內容包含每一項的完整路徑。 三，建立一個虛擬環境，Windows 請建在 C:/cvenv，Mac 請建在家目錄底下的 cvenv，然後安裝 pandas、numpy、matplotlib、jupyter。 四，找出 Rscript 的完整路徑，寫進 ENVIRONMENT.md，並產生一個叫做 run_r 的包裝腳本，讓我以後不必打那串很長的路徑。 五，寫一支 verify_env 的小程式並執行它，逐項印出綠燈或紅燈，包含 Python 版本、每一個套件、以及 R 能不能被叫動。 過程中如果需要我的權限，或需要我做決定，請先停下來問我。不要自己修改系統設定、不要改 PATH、不要動系統內建的 Python。

最後那一句是整段裡最重要的一句

它有能力改你的系統設定，而且改壞了你不會馬上知道。要求它在需要權限的時候停下來問你，你才有機會說不。

一個會自己動手的 AI，跟一個只會回你文字的聊天框，差別就在它真的會改你的電腦。方便和風險是同一件事的兩面。你現在畫的這條線，之後每一次用它處理公司檔案、處理真實資料，都還會再用到。

怎麼知道它真的裝好了

它說「完成了」不算數。下面三項都要親眼看到：

要驗什麼 通過的樣子
每一個套件都真的裝起來 verify_env 逐項印出綠燈，沒有紅燈
R 叫得動 用 run_r 跑出一行 R 的版本資訊
留下可以對照的紀錄 資料夾裡有 ENVIRONMENT.md，裡面每一項都有完整路徑

ENVIRONMENT.md 要留著。換電腦、換學期、套件更新的時候，直接把它貼給 Claude Code 當起點，比從頭來一次快得多。

卡住的時候，這樣講

「不能跑」「壞了」「有錯誤」——這三句話送出去，等於什麼都沒說。一次講三件事：

  1. 我剛剛做了什麼：把你打的指令原封不動貼上，不要重打一次。
  2. 它回了什麼：錯誤訊息貼開頭二十行和結尾二十行。真正的原因常常在開頭，最後一行只是結果。
  3. 我的環境：把 ENVIRONMENT.md 整份貼上。

然後固定加這一句收尾：

請先講你判斷的原因，再給一個最小的修法，不要一次改三個地方。改完告訴我怎麼確認有修好。

為什麼要「一次只改一個地方」？因為一次改三個，修好了你也不知道是哪一個奏效，下次再壞還是只能從頭來。這跟做分析是同一個道理：一次動一個變因，才知道是誰造成的。

這幾種卡點最常見

你會看到 多半是什麼問題 先試什麼
打 python 卻跳出應用程式商店 Windows 的 Python 捷徑擋在前面 把整段畫面貼給它，說「我打 python 出現商店」
一串紅字，提到 script、execution、disabled Windows 的執行原則擋住了 貼完整訊息，並說明你沒有管理員權限
停在要求輸入密碼的畫面 權限問題，不是提示的問題 這一題要去找人，不是找 AI
一直卡著沒反應 多半只是在下載，網路慢 先等三分鐘再說，不要重跑
Rscript 找不到 R 裝了但不在系統的搜尋清單上 這是預設行為不是故障，請它掃出完整路徑

最後那一項要特別講：R 裝完之後不在搜尋清單上是正常的，不是你裝壞了。不要自己去改系統設定，讓它把完整路徑找出來寫進 run_r 就好。
