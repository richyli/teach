Claude Code 指南 0｜總覽與閱讀順序

在本單元中，會介紹一個會動手做事的 AI agent 怎麼在你自己的電腦上跑起來，以及讓它變得「懂你單位」的四個零件：CLAUDE 專案守則、memory、skill、MCP。

這份指南假設你不會寫程式

八份文件都是為了在職媒體主管寫的，不是為工程師寫的。你會被要求做的事只有三件：開資料夾、把話講清楚、看它做完之後驗收。所有出現的程式碼區塊都是「照著貼」的指令，不需要你看懂每一個字。

裡面的每一個範例都來自真實在跑的工作流，包含逐字稿整理、一稿多版、法規逐條比對、週報彙整、政府資料查詢。虛構的示範不會出現在這裡。

Agentic AI 跟你現在用的聊天框差在哪

對話式 AI（網頁版聊天框） Agentic AI（Claude Code）
它做什麼 回你一段文字 讀檔、改檔、跑指令、接外部服務
你做什麼 複製、貼上、再複製 看它做、必要時喊停
出錯時 你重貼一次 它自己跑下一步修
一個指令換來 一段答案 一連串動作加一份成品

再往下分一層，你會看到三種東西常被混在一起講：

會動你的檔案 會臨場判斷 例子
chatbot ✗ ✗（一問一答） 一般對話框
workflow ✓（固定步驟） ✗（照表操課） 自動化腳本
agent ✓ ✓（規劃、執行、看結果再調整） Claude Code

agent 強在會做事又會臨場判斷，代價是你更需要會驗收。這一句是整份指南的主軸。

它比聊天框強的地方，是四個會一直長大的零件

零件 它回答什麼問題 綁在哪 看哪一份
CLAUDE 專案守則 這個資料夾裡的工作要遵守什麼規矩 專案 指南 4
memory 你這個人的偏好與你糾正過的事 你 指南 5
skill 我固定會叫它做的那一串動作 你或專案 指南 6
MCP 它伸手拿得到哪些資料夾以外的料 你或專案 指南 7

一句話記法：CLAUDE 守則是這個專案的規矩，memory 是你這個人的習慣，skill 是你常下的那串指令，MCP 是它伸出去拿料的手。

先判斷你這次的任務要不要用 Claude Code

不是每件事都值得開 Claude Code。純文字任務用免費網頁版就能做完，開 Claude Code 反而多一道手續。

你的任務 用什麼
擬一封信、改寫一段稿、整理一份逐字稿 網頁版聊天框就夠
同一件事你每週都要重做一次 Claude Code，做成 skill
要它讀你電腦裡一整批檔案 Claude Code
要它把結果寫回你的檔案、而且你要逐處核 Claude Code（並排比對）
要它去行事曆、試算表、政府資料庫拿料 Claude Code 加 MCP

第一次上手照這個順序讀

先做（約 60 分鐘，這一輪結束你就能交作業）

  1. 指南 1｜安裝 VS Code
  2. 指南 2｜安裝 Claude Code 並登入
  3. 指南 3｜介面、權限模式與第一個指令

能用之後再讀（每份 15 分鐘，挑你用得到的）

  1. 指南 4｜CLAUDE 檔：專案守則
  2. 指南 5｜memory：跨對話的記憶
  3. 指南 6｜skill：把重複的工作固化
  4. 指南 7｜MCP：接上外部資料

隨時可以翻

  1. 指南 8｜卡住了怎麼辦與安全守則

要開始碰資料的時候再讀（第 9 份起）

前面八份讓它幫你處理文字，第 9 份起讓它幫你處理資料。這兩份與 讓 Claude Code 自己把環境裝好、第一次讓 AI 讀一張表 兩個課堂單元搭配。

  1. 指南 9｜讓它幫你裝 Python 與 R
  2. 指南 10｜鯤島傳媒集團資料包導覽

整條分析線的地圖、十九個練習案例與資料下載，都收在 Hub - 資料分析練習案例庫。

本週作業要交的東西，指南 3 做完就有了

W3 的小作業是：把一段真實工作用 Claude Code 處理，記錄它對的一處與錯的一處，並寫一句「下次我會怎麼改提示」。指南 3 的最後一節就是這件事的操作步驟，跑完把結果留著即可。

W4 的作業是做出一個自己的 skill，指南 6 對應那一週。

動手前先看懂這幾個字

詞 一句話
終端機（terminal） 那個黑底白字、用打字下指令的視窗。Windows 叫 PowerShell，Mac 叫終端機
CLI 用指令操作的程式，相對於用滑鼠點的圖形介面
資料夾（專案） 你啟動 Claude Code 時所在的那個資料夾。它只看得到這裡面的檔
context 這一輪對話它「看得到」的所有文字，包含你打的、它回的、它讀過的檔。有上限
token 模型處理文字的最小單位，也是計價單位。中文大約一個字一到兩個 token
harness 把模型接上你的檔案、權限、外部服務的那層工程。Claude Code 就是一種 harness
diff 改動前後的並排比對畫面，綠色是新增、紅色是刪除
MCP 讓 AI 跟外部服務對話的通用標準，可以想成轉接頭
